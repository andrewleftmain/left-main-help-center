Cadence Automation Readiness Check

Cadence Automation Readiness Check

Audience: Salesforce System Administrators

Overview

The Cadence Automation Readiness Check is an administrative tool that helps your organization prepare before enabling Cadence Automations.

Many Left Main customers already use Salesforce Flows to enroll records into Cadence Libraries, transition records between libraries, or stop active cadences. Cadence Automations may perform some of these same actions.

The Readiness Check identifies active Salesforce Flows that may overlap with the automation being enabled so a Salesforce System Administrator can review them before proceeding.

The check does not change, deactivate, or delete anything in your Salesforce organization.

Administrator Access Required

This article is intended for Salesforce System Administrators and users responsible for managing Salesforce automation. Standard users do not need to run or review the Cadence Automation Readiness Check.

Why the Readiness Check Matters

When a Salesforce Flow and a Cadence Automation perform the same action, both processes may run for the same record.

This can result in:

  • A record being enrolled in more than one cadence

  • Duplicate emails or SMS messages

  • A cadence being stopped and restarted unexpectedly

  • Conflicting or inconsistent automation behavior

The Readiness Check helps administrators identify potential overlaps before activating the Cadence Automation.

Things to Keep in Mind

A Flow appearing in the Readiness Check does not automatically mean it must be disabled. The results identify Flows that require administrator review.

When Does the Readiness Check Run?

The Readiness Check runs when a Salesforce System Administrator turns on a Cadence Automation.

Cadence Automations are disabled by default and can be enabled individually. This allows administrators to review potential conflicts before activating each automation.

What Information Does It Show?

The Readiness Check displays active Salesforce Flows on the applicable object that may overlap with the selected Cadence Automation.

For each Flow, the results may include:

  • A short description of what the Flow does

  • Flow Label

  • Flow API Name

  • A direct link to open the Flow in Salesforce Setup

Administrators can also:

  • Download the full Flow report

  • Enter an email address and email the report

  • Review the results before activating the automation

What Does the Readiness Check Change?

The Readiness Check does not automatically:

  • Activate the Cadence Automation

  • Deactivate a Salesforce Flow

  • Delete a Salesforce Flow

  • Change any Flow settings

  • Modify existing records

  • Enroll records into a Cadence Library

The administrator remains in control of whether to proceed.

What Should an Administrator Do When a Flow Is Listed?

Review whether the Flow performs the same action as the Cadence Automation being enabled.

Determine whether the Flow:

  • Enrolls a new record into a Cadence Library

  • Starts a follow-up cadence after a Status change

  • Enrolls an appointment reminder cadence

  • Stops cadences based on Status or Stage

  • Sends an after-hours response

  • Starts another Cadence Library after the current one completes

For an overlapping process, choose one method:

  1. Keep the Salesforce Flow and leave the overlapping Cadence Automation disabled.

  2. Deactivate the Salesforce Flow and use the Cadence Automation.

Do not run both for the same business process.

Important

When replacing a Salesforce Flow with a Cadence Automation, deactivate the Flow rather than deleting it. This preserves the option to restore the previous configuration if needed.

What If the Flow Performs Additional Actions?

Some Salesforce Flows perform several actions.

For example, a Flow may:

  • Stop a cadence

  • Update record ownership

  • Send an internal notification

  • Create a Task

  • Update another field

Do not deactivate the entire Flow until all of its actions have been reviewed.

If only part of the Flow overlaps with Cadence Automations, the Flow may need to be adjusted rather than disabled completely.

Follow Salesforce best practices by testing any revised Flow before activating changes in production.

What If No Flows Are Listed?

If the Readiness Check does not identify any potentially overlapping active Flows, review the Cadence Automation configuration and proceed with testing.

A clear report does not replace testing. Other automation, manual enrollment, or direct communication processes may still affect the same records.

Guidance for New Left Main Customers

If your organization does not already use custom Salesforce Flows for cadence management, use native Cadence Automations for supported use cases whenever possible.

Native Cadence Automations are generally easier to configure, troubleshoot, and maintain than custom Flow automation.

Recommended Review Process

Before activating an automation:

  1. Run the Cadence Automation Readiness Check.

  2. Review every listed active Flow.

  3. Open potentially overlapping Flows in Salesforce Setup.

  4. Compare each Flow’s trigger, entry conditions, and actions with the Cadence Automation.

  5. Decide which process should remain active.

  6. Configure and test the selected Cadence Automation.

  7. Confirm that records receive the expected cadence and communication.

  8. Deactivate any confirmed overlapping Flows after successful testing.

Testing Recommendations

Test each Cadence Automation before enabling additional automations.

Confirm that:

  • The correct record event triggers the automation.

  • The expected Cadence Library is applied.

  • Only one cadence is enrolled.

  • Emails and SMS messages are not duplicated.

  • Stop rules work as expected.

  • Follow-up or appointment cadences replace the current cadence correctly.

  • Existing Salesforce automation continues to perform any required non-cadence actions.

Whenever possible, test in a Salesforce Sandbox before enabling the automation in production.

Frequently Asked Questions

Does the Readiness Check decide whether a Flow conflicts?

No. It identifies active Flows that may overlap. A Salesforce System Administrator must review the Flow’s trigger, conditions, and actions to determine whether there is a true conflict.

Will the Readiness Check deactivate my Flows?

No. It is a review and reporting tool only.

Can I keep my existing Flow?

Yes. Keep the Flow active and leave the overlapping Cadence Automation disabled.

Can I use both if they perform similar actions?

Using both for the same business process is not recommended. It may result in duplicate enrollment, duplicate communication, or inconsistent cadence behavior.

Should I delete a Flow I no longer need?

No. Deactivate it so the organization retains a rollback option.

Can I save the results?

Yes. Administrators can download the full report or email it to a selected email address.

Why do I see a Flow that does not appear to manage cadences?

The Flow may run on the same object or update a field monitored by the Cadence Automation. Review its trigger, entry conditions, and actions before deciding whether it is relevant.

Pro Tip 🧠

Enable and test one Cadence Automation at a time. This makes it easier to identify overlapping Salesforce Flows and confirm which automation caused a record to enroll, transition, or stop.
