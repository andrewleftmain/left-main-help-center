Release Notes

Cadence and DispoSignals Release Notes v1.606

Release Date: June 7, 2026

Updates included in this release will be deployed in batches between Sunday, June 7, 2026 and Thursday, June 11, 2026. Some customers may receive these enhancements earlier than others during the rollout period.

Summary

This release includes improvements to Cadences and DispoSignals focused on visibility, reliability, administrative controls, and scheduling flexibility. Customers will also see new scheduling options for Follow-Up Sequences, improved Cadence Timeline visibility, and expanded property insights throughout DispoSignals.

New Features

Past Date Cadence Steps

Admins will now see a new Past Date Cadence Steps section at the bottom of the Cadence Library timeline. Cadence steps scheduled for a date that has already passed will appear here instead of being hidden, giving admins full visibility and the ability to update or remove those steps.

Subject Property Snapshot Added Across DispoSignals

A Subject Property Snapshot is now available throughout DispoSignals, providing quick access to key property details including address, beds, baths, square footage, lot size, year built, last sale price, and last sale date.

Enhancements

Follow-Up Sequence Frequency Values

Specific Date and Specific Day of the Week Frequency values are now available for use on Follow-Up Sequences. New orgs will receive these values automatically. Swantide customers will receive them through an automated workflow. Existing customers without Swantide can follow the provided setup instructions to add these values to their org.

Auto Populate Lot Size and Year Built on Retail Comps

Running Retail Comps in DispoSignals will now automatically populate Lot Size and Year Built on Opportunities using data from the subject property when those fields are blank.

Improved Cadence Timeline Audit Trail

The most recent Cadence Library applied to a record will now always remain visible on the Cadence Timeline, providing an audit trail of activity.

Legacy Email Follow-Up Sequence Compatibility

When adding templates or folders to a Cadence Library, any Email Follow-Up Sequence missing a Related Object will now automatically inherit the library's Related Object, ensuring all valid templates are visible and usable.

Updated Follow-Up Sequence Clone Experience

The Clone button on Follow-Up Sequences has been updated to use the new, modern Follow-Up Sequence modal.

Bug Fixes

Cadence Stop Reliability

Fixed an issue where Cadence stop logic could fail silently when processing was triggered at the end of a batch job. Cadence stop behavior will now complete reliably in all contexts.

Cadence Library Deletion Permissions

The ability to delete Cadence Libraries is now restricted to admin users only.

Dialpad SMS Cadence Sending

Fixed an error that prevented Dialpad SMS Cadences from sending when a Lead was associated with a Campaign.

Disabled Channel Enforcement

Fixed an issue where disabling a communication channel in Cadence Setup did not prevent that channel's steps from executing.

Draft Cadence Library Validation

Flows will now fail gracefully if the referenced Cadence Library is in Draft status, preventing Draft libraries from being assigned to records. Flow owners will receive an email notification explaining the failure. If you receive this notification, look for the message "Cadence Library in Draft Status" and update the Flow to reference an Active Cadence Library.

Duplicate Buyer Prevention

DispoSignals now better handles entity-only buyer records, preventing duplicate Contacts and Accounts from being created when matching buyer information is added later.

Buyer Record Type Assignment

Contacts created through DispoSignals will now be assigned the Buyer record type instead of the Homeowner record type.

Admin Action Required

New Follow-Up Sequence Frequency Options

This release introduces two new Follow-Up Sequence Frequency values:

  • Specific Date

  • Specific Day of the Week

What you need to know:

  • New orgs will receive these values automatically.

  • Swantide customers will receive these values through an automated workflow.

  • Customers not using Swantide may need to manually add these values to their org before they become available for use.

Setup Instructions:
https://scribehow.com/viewer/How_to_Update_the_Frequency_Field_in_Email_Follow_Up__Z_m5ZJ4JRnWsPRPsg-_mjg

Recommendation: After updating the picklist values, review your existing Follow-Up Sequences to determine if any would benefit from the new scheduling options.
