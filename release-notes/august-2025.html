Release Notes

August 2025

What’s New in 1.558

This release focuses on high-impact, customer-requested enhancements to improve how users access, track, and manage property sales data. All updates apply exclusively to customers who havepurchasedProperty Sales AIand aim to streamline workflows, improve visibility, and offer greater customization.

✅ Easier Upgrades

We’ve made upgrades simpler! Starting with this release, many post-install steps that used to be done manually can now be handled automatically. To activate this new automation for this and all future updates, just submit a one-time request to Left Main Support (support@leftmainrei.com) — we’ll take care of the rest.

🏠 Parcel ID Now Included

Highly requested by Customers seeking a reliable property identifier.

Customers can now search and filter Property Sales records using Parcel ID, making it easier to link transactions to public records, MLS data, or internal property systems.

📈 Recently Updated Sales Visibility Records

Improves transparency and reduces guesswork around data freshness.

Property Sales AI now flagsupdates to buyer and seller information, so customers can quickly identify which sales records have changed recently.

🔢 Property Sales Count per Property

Great for spotting investor behavior and property turnover at a glance.

Instantly see how many times a property has sold (since Property Sales AI subscription started). No manual counting or customization required.

🛠️ Advanced Customer-Defined Matching Logic

Increases precision for customers managing large or complex lead datasets.

Customers can now apply custom filters to the Property Sales AI matching engine, such as:

  • Excluding low-price sales

  • Ignoring certain properties

  • Applying geographic or ownership filters

If you want to take advantage of this new feature, please log a case with Left Main Support at support@leftmainrei.com and we will happily configure it for you. 


📌 Optional Task Logging for Lead/Opportunity Matches

Helps reduce task clutter and streamline activity tracking based on team preferences.

Admins can now disable the automatic creation of Salesforce tasks when Property Sales AI identifies a match.

If you want to take advantage of this new feature and disable the automatic Task creation, please log a case with Left Main Support at support@leftmainrei.com and we will happily enable it for you.
