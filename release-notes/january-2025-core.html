What’s New?

Enter a New Era of Revenue Generation with Property Sales AI

Property Sales AI is a groundbreaking tool designed to help you close deals faster and smarter by automatically closing out leads and opportunities when properties are recorded by the county. Key benefits include the following:

Reduce Costs. Automatically close out leads and opportunities when properties are recorded by the county as sold, freeing up time for higher-value tasks and money on phone usage, direct mail and follow-up costs.

Drive Revenue. Prioritize leads and opportunities based on sold property data to focus your efforts on deals ready to convert and capture gaps in your follow-up process.

Gain Unprecedented Insight Into Your Competition. Track activity of local investors, monitor your sales pipeline and merge local market data with CRM data, helping you make smarter, data-driven decisions.

Explore Property Sales AI in Your Org Today

Click here to log into your org, dive into the full capabilities of Property Sales AI and kick off the onboarding process!

Core Enhancements

NEW Permission Set Required

Due to security enhancements and Salesforce requirements, a new permission set granting access to the following is required for all users. Brand new customers will receive this permission set by default. Current Left Main customers will need to follow the instructions below to manually create and assign this new permission set (access the Create "Left Main User (Salesforce Required)" Permission Set and Assign to All Users guide here).

  • Edit Tasks

  • Run Flow

  • Field-level security Access to Tasks fields

  • Field-level security granted to the standard Description field on the Lead object

  • Field-level security granted to the standard Fax field on the Lead Object

Clarification on Left Main Permission Sets

Left Main Support Tab

This tab now includes Professional Services in the ticket type dropdown. A link to How To Grant Left Main Access To Your Org instructions was also added to the Left Main Support tab confirmation page.

Improvements

RingCentral Integration

This integration was previously disabled due to RingCentral's improved authentication method. Revised documentation on Cadences Configuration for RingCentral is available here.

Bug Fixes 🐞

Bulk Add Cadence Buttons Fix

In some scenarios, users were selecting the Bulk Add Cadence button multiple times, resulting in multiple active Cadences being created on a single record. Bug is now resolved on the Leads, Opportunities, Contacts, Transactions and Interested Buyers objects.
