Release Notes for Version 1.569

Cadence Setup Wizard (Demo)

Setting up Cadences is now faster and easier than ever!
Admins no longer need to navigate Salesforce Setup to configure Cadences. The new Cadence Setup Wizard, available in the Cadence App Configuration app, centralizes all setup options in one place.

Highlights

  • Default SMS Sending Numbers: Choose the preferred “From” number — Record Owner, User Profile, or Org-Wide — and rank fallback options.
  • Default Email Addresses: View who scheduled cadence emails send from and optionally choose an Org-Wide Email Address to use as the default sender.
  • Productized Automations: Toggle built-in rules to automatically stop Cadences when leads convert or receive inbound communication.
  • Advanced Settings (New!):
  • Use the Recipient's Phone field as a fallback for SMS sends.
  • Enable timezone fallbacks to ensure accurate send times.

No action required — existing settings are automatically preserved.
We recommend exploring the new Setup Wizard to take advantage of org-wide defaults and advanced automation options.

How to Use the New Setup Wizard

  1. Navigate to Cadence App Configuration → See new Cadence Setup tab.
  2. Review and confirm your default SMS and email sender preferences.
  3. View the Automations tab to enable or disable automatic cadence stop rules.
  4. Configure Advanced Settings to define working hours and additional Phone field options.
  5. Click Save to apply settings.

Tip: Changes made in the Setup Wizard apply upon save and can be updated anytime by Cadence Admins. {height="" width=""}

Enhanced Cadence Tracking & Status Visibility

We’ve added two new fields to improve transparency into cadence activity:
- Stopped Reason – Provides context on why a cadence stopped (e.g., manual or automation).
- Stopped Timestamp – Automatically captures the exact time a cadence stopped, displayed in your org’s local timezone.

When a cadence is stopped, all pending activities (emails, texts, calls, tasks) are canceled and marked with a new Canceled status on the Cadence object — ensuring clear visibility between completed and canceled actions.
{height="" width=""}

Timezone-Aware Messaging

Cadence Date/Time fields now honor the recipient’s local timezone when scheduling sends, ensuring messages reach recipients at the right time — no manual adjustments needed.

DealSignals (Demo)

Smarter Enrichment, Deeper Insights We’re excited to announce the November release of DealSignals, bringing two new stress indicators and expanded property attributes to help users identify opportunities and risk with even greater precision.

New Stress Indicators DealSignals now automatically detects and surfaces two new stress indicators within the Enriched Property Data Lightning Web Component:

Utility Liens – Identify properties carrying unpaid utility obligations, a common signal of financial distress.

Divorce Judgments – Detect potential ownership changes or motivated sellers due to recent divorce-related judgments. {height="" width=""}

Additional Property Attributes We’ve expanded the dataset available through the Enrichment Flow to include a richer view of mortgage and lien activity. These fields will soon also be available for new prospect subscriptions, allowing even more granular targeting. New Attributes:

  • Assessor’s Parcel Number
  • Subdivision Name
  • Mortgage Recording Date
  • Mortgage Loan Amount
  • Mortgage Loan Type
  • Mortgage Interest Rate
  • Involuntary Lien Type
  • Involuntary Lien Judgment Amount
  • Involuntary Lien Amount
  • Involuntary Lien Recording Date
  • Involuntary Lien Parties Full Name
