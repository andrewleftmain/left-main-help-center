New “Property Sale Duration” Field Available as of May 8, 2025

A new field, Property Sale Duration, has been added to the Subscription page layout. Use this field to set the number of days used to determine whether multiple Property Sales records should be treated as duplicates.

This field helps you manage data hygiene by accounting for variations in local recording timelines. If two property sales share the same LFID (unique identifier) and occur within the number of days specified here, they’ll be considered duplicates. If outside of the date range specified here, they’ll be treated as uniquely separate transactions. Different values may be used per county.

We recommend entering a value between 7 and 20 days to reduce false duplicates while preserving legitimate sales activity.
