TWNSQR Integration Deprecated

The Left Main - TWNSQR integration has been deprecated and is no longer functional. Thus, it is safe to remove TWNSQR components from your Left Main pages. This step ensures that your visual layout remains uncluttered and that you are not relying on obsolete functionalities.

How to Remove a Visualforce Page Component from Lightning Pages in Salesforce

This article outlines the steps to follow, specifically for the objects: Leads, Opportunities, and Transactions.

Steps to Remove Visualforce Page Components

To successfully remove the Visualforce page component, please follow these steps:

  1. Log in to your Left Main account.

  2. Navigate to the Setup section. This can usually be found in the upper right corner of the screen.

  3. In the Quick Find box, type Object Manager and select it.

  4. Choose the object from which you want to remove the Visualforce page component(Leads, Opportunities, or Transactions).

  5. Once on the object page, select Lightning Record Pages.

  6. Locate the Lightning Record Page that contains the Visualforce component you wish to remove.

  7. Click on the edit icon next to the Lightning Record Page name.

  8. In the Lightning App Builder, find the “twnsqr” Visualforce component within the layout. It will look like this:

  9. Select the Visualforce component and click the Remove button, which is typically represented by a trash can icon.

  10. After removing the component, click Save in the upper right corner.

  11. Finally, click Activation to ensure that changes reflect on the desired Lightning pages.

By following these steps, you can efficiently remove any unnecessary Visualforce page components and streamline your Lightning page layouts.

Conclusion

Removing outdated or non-functional components, like those tied to the TWNSQR integration, helps to keep your Left Main environment clean and efficient. Doing this allows for better performance and improved user experience for your team members.
