DealSignals Setup and Onboarding

Internal use only

Use this guide to configure DealSignals in a customer Salesforce org, including package readiness, permissions, feature parameters, authentication, setup-wizard selections, page layouts, reporting assets, county requests, and Professional Services handoff.

Pre-Enablement Checklist

  • Ensure you have subscriber login or direct login access via a System Administrator user to access the customer's org. See Step 1 to determine which type of access is required.

  • You can access the License Management App (LMA) and customer feature parameters.

  • You know whether the customer is a trial customer and, if applicable, the trial expiration date.

  • You know the purchased counties and stress-event subscription types.

  • Sign in with direct Left Main login credentials.

Step 1: Determine Which Client App Path Applies

Note: Starting with the release of v1.615 on August 4, 2026, existing customers will use the Left Main External Client App instead of the legacy Left Main Connected App. Before installing or configuring a client app, confirm whether the customer is net new to Left Main, an existing customer and whether the customer already uses DispoSignals.

Path A: Net-New Left Main Customer

Use this path when:

  • The customer is being onboarded to Left Main for the first time as of August 4, 2026 to present.

  • The customer purchased DealSignals.

  • The TSO includes the Left Main External Client App managed package.

The External Client App package should already be installed through the TSO process.

Proceed to Step 1.1: Verify and Configure the Left Main External Client App.

Path B: Existing Left Main Customer Adding DealSignals

Use this path when:

  • The customer was already a Left Main customer before August 4, 2026.

  • The customer is adding DispoSignals.

  • The customer does not already use DealSignals through the legacy Left Main Connected App.

Install and configure the Left Main External Client App managed package.

Direct login access through a System Administrator user is required for installation; Subscriber login access cannot be used.

Proceed to Step 1.1: Verify and Configure the Left Main External Client App.

Path C: Existing DispoSignals Customer Adding DealSignals

Use this path when:

  • The customer already uses DispoSignals prior to August 4, 2026.

  • DispoSignals was configured using the legacy Left Main Connected App.

  • The customer is now adding DealSignals.

Leave the existing Connected App configuration as-is.

Do not:

  • Install the Left Main External Client App package.

  • Configure an External Client App.

  • Migrate the customer from the Connected App.

  • Configure both client apps.

The required Connected App configuration should already have been completed during DispoSignals onboarding.

Proceed to Step 1.2: Legacy Connected App Configuration Reference.

Important: Existing DispoSignals customers should continue using their current Connected App configuration when DealSignals is activated

Step 1.1: Verify and Configure the Left Main External Client App

Complete this section for Path A and Path B only.

Verify the Managed Package

  • For Path A, the package should already be installed through the TSO.

  • For Path B, install the package using the approved managed-package URL if it is not already present.

Install URL: https://login.salesforce.com/packaging/installPackage.apexp?p0=04tR7000000KbbJIAS

To verify the package is installed:

  • Go to Setup → Installed Packages

  • Confirm the Left Main External Client App package appears in the list.

Configure OAuth Policies

  1. Navigate to:

    Setup → External Client App Manager

  1. Open Left Main External Client App

  1. Click Edit

  1. Expand OAuth Policies

  1. Set Permitted Users to:

    Admin approved users are pre-authorized

  1. Save.

Grant Profile Access

Grant access to the External Client App for:

  • Left Main System Administrator

    and/or

  • System Administrator

If the customer uses custom administrator profiles, grant those profiles access as well.

Once complete, continue with the remaining DispoSignals onboarding steps.

  • ClickManage Profiles

System Administrator
and/or
Left main System Administrator

  • Click Save

Step 3: Enable Feature Parameters in LMA

  1. In the app launcher search box, type in Feature Parameters.

  2. Click on the feature parameter. Ex: FP-0002. Click on Related tab.

  3. Under Feature Parameter Booleans, click View All.

  4. Find account name. On the right side, click down arrow and click Edit.

  5. Check Feature Parameter Value box. Click Save.

  6. Repeat for all Feature Parameters

  7. For FP-0006, under Feature Parameter Dates, click View All. Enter the trial expiration date (typically two weeks after trial begins).

Note: Once trial is concluded, the date needs to be changed back to 12/31/2023.

Step 4: Open DealSignals Setup Wizard and Authenticate

  1. Return to the customer Salesforce org.

  2. Open DealSignals Setup Wizard in the app launcher.

  3. Allow browser pop-ups.

  4. Select Authenticate in the setup wizard left sidebar.

  5. Complete the authentication flow.

Step 5: Select Configuration Criteria

Configure Leads

Note: Confirm with the customer which lead record types and lead statuses they want to select. Lead address fields can be verified using Salesforce Inspector. Some customers may have custom fields.

  1. Select the applicable Record Types and click Save.

  2. Select the applicable Lead Statuses and click Save.

  3. Select the Lead Address Fields for Matching.

Record any unavailable county or stress-event selections.

Submit unavailable county and stress-event requests to the Product Team through the approved request process.

Opportunity Preferences

Note: Confirm with the customer which opportunity lead record type and opportunity stages they want to select. Opportunity address fields can be verified using Salesforce Inspector. Some customers may have custom fields.

  1. Select the applicable Record Types and click Save.

  2. Select the applicable Opportunity Stages to Include and click Save. Note: The list will include inactive values. To check, go to Setup > Object Manager > Opportunity > Fields & Relationships > Stage > Opportunity Stages Picklist Values.

  3. Select the Opportunity Address Fields for Matching.

Configure New Prospects

If customer does not want to new leads created through DealSignals, click Skip. Otherwise, continue below:

  1. Select Status.

  2. Select Lead Source DealSignals (unless customer has custom preference).

  3. Select Record Type. Recommendation is to use Prospect.

  4. Click Save.

  5. For subscriptions, select Subscription Type. These are the stress events.

  6. Select Subscription Location. These are the counties the customer has included in their subscription. Customer may want all counties or some counties enabled. Multiple locations can be selected at the same time for each subscription.

  7. Continue with Add Subscriptions to add more.

  8. Once all subscriptions have been added, click Save.

  9. For any subscriptions that were not able to be added, please submit the request to add via the DealSignals County Requests google form.

Advanced Settings

  1. Notification Events: Select which DealSignals events should trigger notifications. Confirm with the customer.

  2. Select Recipients: Choose who should receive notifications (Record owner and/or Specific User). If Specific User is selected, you can select one or multiple users at the same time.

  3. Delivery Method: Select how notifications should be delivered (Notification in-app alert or Task created and assigned to recipient).

  4. Trigger Behavior: Select when notifications should fire: Insert only, Update only, or Both.

  5. Click Save.

Step 6: Finish the Setup Wizard

  1. Review all selections.

  2. Select Finish.

  3. Confirm the wizard completes successfully.

Step 7: Update Salesforce Page Layouts

  1. In the app launcher, go back to Left Main+.

  2. Go to Leads and click on any Lead.

  3. Click on gear icon. Click Edit Page.

  4. Search for Enrich. Drag lmrEnrichmentRelatedPropertyInfo to the page layout. Customer may have a preference. Recommend on left side panel.

  5. Click Save.

  6. From lead object, click on gear icon and click Setup.

  7. Go to Page Layouts.

  8. Click on page layout name (this step may need to be repeated for all relevant page layouts).

  9. Click on Related Lists.

  10. Select Contacts and drag to Related List section. Customize fields to display with wrench icon.

  11. Go back to Left Main+. Go to Opportunities and click on any Opportunity.

  12. Click on gear icon. Click Edit Page.

  13. Search for Enrich. Drag lmrEnrichmentRelatedPropertyInfo to the page layout. Customer may have a preference. Recommend on left side panel.

  14. Click Save.

  15. Go to gear icon and click Setup.

Step 8: Initiate Swantide Workflow

  1. Under account, click on Create DealSignals/Swantide Case. This will notify the Support team to initiate the Swantide workflow to install the DealSignals dashboard and reports.

Step 9: Customer Onboarding Meeting

  1. Once the DealSignals dashboard and reports have been added, confirm customer onboarding meeting.

  2. In the meeting, confirm setup if you have not already.

  3. Open up the DealSignals dashboard. Go over in detail specifically highlighting Hot List and New Prospects Generated This Week reports.

  4. Go over the stress indicators and what they mean.

  5. Discuss common ways to work the leads and opportunities.

  6. Property Sales AI is included with DealSignals. Make sure that set up is complete (if they do not already have the add-on) and do onboarding for Property Sales AI. Reference documentation in the Resources section below.
