Getting Started with DispoSignals

Release Date: May 21, 2026

Welcome

DispoSignals helps you identify potential buyers, analyze investor demand, and evaluate pricing opportunities directly within your CRM workflow. With just a few clicks, you can generate buyer insights and comparable sales data from your Opportunities or Transactions.

Step 1: Setup

DispoSignals is enabled through Left Main.

  • Access must be enabled by the Left Main team. Please reach out to your Customer Success or Implementation Specialist contact to coordinate onboarding.

  • Once enabled, your organization will have access to DispoSignals functionality .

Step 2: Assign Permission Sets


Left Main DispoSignals Admin

  • Access to: Everything DispoSignals User can access, plus DispoSignals runs object and product authentication

  • Restrictions: Cannot view transactions or interested buyers (see Left Main Dispo User permission set below for additional access)

  • Who: Admins setting up/activating the product for the first time

Left Main DispoSignals User

  • Grants access to: Investor Activity, Retail Comps, Investor Comps

  • Restrictions: Cannot view transactions or interested buyers (see Left Main Dispo User permission set below for additional access)

  • Who: Users with basic DispoSignals access only

Left Main Dispo User

  • Grants access to: CRM Comps, Internal Buyers Lists, External Buyers Lists

  • Required alongside Left Main DispoSignals User permission set to access all Dispo features

  • Who: Users needing full dispositions functionality

Step 3: Start Using DispoSignals

Once setup is complete:

  1. Open an Opportunity or Transaction record

  2. Go to DispoSignals Tab

  3. Run:

    • Investor Activity

    • Investor Summary

    • Investor Comps

    • Retail Comps

    • Buyer Search

  4. Review results and take action directly within the platform

No additional integrations or external tools are required.

Recommended Workflow

  • Start with Investor Activity and Investor Summary from the Opportunity record to evaluate buyer demand and pricing trends.

  • Use Investor, Retail, and CRM Comps from the Opportunity record to validate pricing strategy and exit opportunities.

  • Use Buyer Search from the Transactions object when ready to identify and contact likely buyers.

  • Note: To save time, you can run Full Property Analysis, which runs Investor Activity, Investor Summary, Investor Comps, and Retail Comps in a single action.
