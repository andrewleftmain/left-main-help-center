How-To-Use Guide

Create a New Email Follow Up Sequence

  1. Navigate to the Email Template Follow Up Sequences Tab

  2. Click New

  3. Complete the four sections in the New Email Template Modal:

    1. Template Details

      1. Select the Object this template will be used for

      2. (Optional) Select a From Email Address to override the default set in the Cadence Setup Wizard

      3. Choose an existing Folder or click + Create New to add a new folder

        1. Selecting Create New opens a new tab in Salesforce Setup where you can create the folder

        2. Save the folder, close the tab, and return to the Email Template modal

    2. Select or Create a New Email Template

      1. To use an existing Email Template, search for and select it from the dropdown

        1. Note: This list will be filtered by the selected Object in the Template Details section for Lightning Templates, but all Classic templates in the org will be in the list. It is important to verify that the Classic template is aligned to the object you are creating the Follow Up Sequence for.

      2. To create a new Lightning Email Template, choose one of the two options:

        1. Basic Editor

          1. Click Basic Editor

          2. Enter a Template Name

          3. Confirm or select the Object the template applies to

          4. Add an optional Description to help identify the template later

          5. Enter the Subject Line and Email Body

            1. Use the Merge Field Picker to insert Merge Fields where needed

          6. Click Save to return to the Follow Up Sequence modal. The new template will be automatically selected

        2. Salesforce Lightning Builder Experience

          1. Click Salesforce Builder Experience

          2. Enter a Template Name

          3. Confirm or select the Object the template applies to

          4. Enter the Subject Line, inserting merge fields as needed

          5. Click Save and Open Builder to launch the Salesforce Lightning Email Builder in a new tab

          6. Use drag-and-drop components (such as text, images, buttons, or HTML) to design your email

            1. For a more in-depth guide to the Salesforce Builder Experience, reference this guide from Salesforce

          7. Click Save, the close the tab and return to the Email Follow Up Sequence modal. The template will already be selected

    3. Schedule Message

      1. Choose when the email should be sent:

        1. Immediately - Sends as soon as the Cadence is applied

        2. After X Minutes / Hours / Days - Sends after a defined delay

        3. On a Specific Day of the Week - Sends at a set time on a recurring weekday schedule

        4. On a Specific Date - Sends on a specific date and time

    4. Message Preview

      1. Select a record to use for previewing

        1. Note: The options listed will be the most recent 100 records created of that record type

        2. Note: If a classic email template has been selected, you will be directed to preview in a new tab.

      2. Enter a Preview Email Address

      3. Click Send Preview Email

      4. Check the inbox (and spam folder, if needed) for the preview email

  4. Click Save

  5. You’ll be taken to the Email Follow Up Sequence record, where you can continue testing previews

  6. Click the Email Template Follow Up Sequences tab to return to the full list of templates

One-Time Setup Steps

  1. Lightning Email Template Builder Permissions

    a. To enable users to create new Lightning email templates using the drag-and-drop builder, admins must perform a one-time post-install configuration:

    1. i. Navigate to Setup

    2. ii. Search for and Select Permission Sets

    3. iii. Create a new Permission Set by clicking New Permission Set, set a name (e.g., “Template Builder”), and Save

    4. iv. Scroll to find System Permissions. In System Permissions, click edit and enable:

      • Access drag-and-drop content builder (Lightning builder access)

      • Manage Public Lightning Email Templates (ability to create templates)

    5. v. Save

    6. vi. Assign this Permission Set to any users who need to create or edit Lightning email templates. This will likely be all users who have the Left Main Cadence Permission Set.

    Notes:

    • This step is only for users who build templates; all other users can still use existing templates without the permission.

    • Without these permissions, attempts to create new Lightning email templates will result in Salesforce errors

Link to In-Depth walkthrough

  1. Enable Lightning Email Templates

  1. To create new Email templates using the enhanced Lightning experience, Salesforce requires that Lightning Email Templates are enabled in your org. This is a one-time Salesforce setting and is the only action needed after installing the update.

  2. How to enable Lightning Email Templates:

  1. Navigate to Setup

  2. Search for Lightning Email Templates

  3. Select Lightning Email Templates

  4. Turn Folders and Enhanced Sharing ON

Once enabled, your team will have access to the new Email Template editors, including the Basic Editor and the Salesforce drag-and-drop Email Builder. No further migration steps are necessary.
