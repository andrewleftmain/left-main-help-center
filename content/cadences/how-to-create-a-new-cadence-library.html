Create a New Cadence Library

  1. Navigate to Cadence App Configuration in Salesforce.

  2. Click the Cadence Library tab to view all existing libraries. (Optional: Sort by object type.)

  3. Click New to create a Cadence Library.

  4. Enter Name, Description, and Related Object Type.

  5. Click Save.

  6. You will be redirected to the newly created Cadence Library.

Add Templates to the Cadence Library

Option 1: Create a New Template

  1. Click + Create New Template.

  2. Build a new follow-up sequence (any channel type).

  3. Click Save. The template will be added in chronological order.

Option 2: Add an Existing Template

  1. Click + Add Existing Template.

  2. Select the channel type.

  3. Choose the desired template.

  4. Click Add to Cadence. The template will be added in chronological order.

Option 3: Add an Existing Folder (Legacy Option)

  1. Click + Add Existing Folder.

  2. Select the folder to import. Note: This is a temporary option used during migration.

Key Notes

  • Templates are automatically organized in chronological order.

  • You can mix new templates, existing templates, and legacy folders.

  • The Cadence Library is a centralized location for managing follow-up sequences.
