Steps

Create a New Direct Mail Follow up Sequence

  1. Navigate to the Direct Mail Follow Up Sequences tab.

  2. Click New.

  3. Complete the four sections in the New SMS Template modal:

    1. Template Details

      1. Enter a Template Name.

      2. Select the Object this template will be used for.

      3. Choose an existing Folder, or click + Create Newto add a new folder.

        1. Selecting Create New opens a new tab in Setup where you can create the folder.

        2. Once saved, close the tab and return to the Direct Mail Template modal.

    2. Select a Piece of Direct Mail

      1. From the picklist options, select a piece of Direct Mail for this template. The picklist is sorted by the Selected Object.

      2. Alternatively, click +Create New to be re-directed to PostcardMania to create a brand new piece of Direct Mail

    3. Schedule Message

      1. Choose when the Direct Mail should be sent once the Cadence step is applied:

        1. Immediately – Sends as soon as the step is applied.

        2. After X Days– Sends after a specified delay.

        3. On a Specific Day of the Week – Sends on a selected weekday and can repeat for multiple weeks.

        4. On a Specific Date – Sends on an exact date.

    4. Message Preview

      1. Preview the piece of mail

  4. Click Save.

  5. You’ll be taken to the Direct Mail Follow Up Sequence record

  6. Click the Direct Mail Follow Up Sequences tab to return to the full template list.

Edit an Existing Direct Mail Template

  1. Navigate to the Direct Mail Follow Up Sequences tab.

  2. Select a Follow up Sequence from the list view.

  3. Click Edit Template.

  4. You will be re-directed to PostcardManiaMake to make your updates.

  5. Click Save.
