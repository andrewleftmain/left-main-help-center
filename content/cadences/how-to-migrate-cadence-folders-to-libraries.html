Migrating Cadence Folders Into a New Library

Create a Cadence Library from Existing Folders

  1. Navigate to the Cadence App Configuration app.

  2. Go to Cadence Setup.

  3. Click '+ Create Library from Existing Folders'.

  4. Enter a name for the new Cadence Library.

  5. Select a record type for the Cadence Library.

  6. Add a description for the library.

  7. Select SMS folders to include using the arrow controls.

  8. Confirm the selected SMS folders.

  9. Select email folders to include using the arrow controls.

  10. Confirm the selected email folders.

  11. Review your selections.

  12. Save the new Cadence Library.

  13. Verify that the folders have been migrated successfully.

  14. Open the new library to confirm templates and sequences.

  15. Make any necessary adjustments.

  16. Activate or begin using the new Cadence Library.

Key Notes

  • This process helps consolidate legacy cadence folders into a centralized library.

  • Both SMS and email folders can be migrated into the same Cadence Library.

  • Review all migrated content to ensure accuracy before using in production.

  • After migration, Cadence Libraries should be used instead of legacy folders.
