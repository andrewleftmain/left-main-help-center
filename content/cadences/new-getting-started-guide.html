Set Up or Switch Your CTI Provider for Cadence SMS

Overview

Vonage is now available as a CTI provider in Left Main. Use this guide to set up Vonage as your CTI provider in Cadence Setup — whether you're a new customer completing implementation or an existing customer switching to Vonage.

Prerequisites

  • System Administrator (or equivalent) Salesforce permissions.

  • Your Vonage credentials from your Vonage account: API Key, API Secret, Application ID, and your default sending number.

Steps

  1. Navigate to Cadence App Configuration and open Cadence Setup.

  2. Click Edit.

  3. Scroll to step 2, Configure Outbound SMS Provider, and click Change SMS Provider.

  4. In the SMS Provider field, open the dropdown and select Vonage.

  5. Enter your Vonage API Key, API Secret, Application ID, and default sending number in the fields that appear.

  6. Click Save and Lock Provider.

  7. Step 3 -

Note: Once you click out of a credential field, the value is hidden and can't be viewed again. If you need to change it later, just re-enter it.

Expected Outcome

Vonage is set as your SMS provider for Cadences, and outbound SMS sends from the number you configured. We recommend sending a test SMS to a test record to confirm everything is working properly.

Things to Keep in Mind

  • If you're already set up with a working CTI provider and aren't switching, you don't need to do anything — your current setup carries over.

  • New customers: the Left Main implementation team will complete this setup with you during implementation.


Pro Tip 🧠

Have your Vonage credentials ready from your Vonage account portal before you start, so you're not searching for them mid-setup.
