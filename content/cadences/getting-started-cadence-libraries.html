Getting Started with Cadence Libraries

Release Date: April 29, 2026

Welcome

Cadence Libraries give you a single, organized place to build and manage outreach sequences across every channel — SMS, email, tasks, and direct mail. This guide walks you through how to activate the feature, build your first library, migrate existing folder-based Cadences, and update any Flows you use for automated cadence enrollment.

Step 1: Migrate Existing Folder-Based Cadences

  • The first thing to do before building anything new is bring your existing folder-based cadences into the library system. This ensures nothing gets left behind and gives you a clean foundation to work from.

    • Navigate to the Cadences App Configuration app in Salesforce and open the Cadences Setup tab.

    • At the bottom of the page, click Migrate Folders to Cadence Library.

    • From here, select as many folders per channel type as desired — SMS, Email, Task, and Direct Mail — and combine them into a single Cadence Library.

    • Give the library a name and description, then save.

    • On save, the new library is created and you're taken directly to it to review, adjust, and complete it before setting the status to Active.

    • Repeat this process for each group of folders you want to consolidate into its own library.

    ⚠️ Things to Keep in Mind Existing folder-based cadences on records are not affected by migration — they continue running normally throughout the transition. You don't need to stop anything before migrating.

Step 2: Build New Cadence Libraries

Once your existing folders are migrated, you can start building new libraries from scratch — or continue pulling in any remaining folders you didn't catch in Step 1.

  • From the Cadences App Configuration app, click the Cadence Library tab.

  • Click New to create a library.

  • Give it a name, a description (this is what end users see when choosing a library, so make it clear and specific), and select the target object type — Lead, Contact, Opportunity, Transaction, or Interested Buyer.

  • The library starts in Draft status. It will not be available for use on records until you set it to Active.

  • Open the library and you have three options to add templates:

    • Create New Template — Build a new SMS, email, task, or direct mail sequence directly in the library builder. Select the template type, fill in the name, message content, and schedule. A live preview panel on the right lets you select a real record to resolve merge fields before saving.

    • Add Existing Template — Pull in a template that already exists in your org. Filter by template type and the library's object type to find compatible options. A preview displays the template content before you add it.

    • Add Existing Folder — If you have remaining folders that weren't migrated in Step 1, use this to import all unlinked sequences from up to one folder per channel type directly into the library you're building.

  • Steps appear in the timeline in chronological order. The number of days between touchpoints is shown in green, giving you a clear view of pacing and density.

  • When your library is complete, click Change Status to set it to Active. Only Active libraries appear in the cadence picker when end users create cadences on records.

⚠️ Things to Keep in Mind — The + Add Existing Folder button and the migration wizard from Step 1 are transition tools — they'll be hidden once you complete the full cutover to Cadence Libraries in Step 5. Use them now while you're in the migration phase.

🧠 Pro Tip — Use the Preview Record field in the Builder to select a real record from your org. All merge fields in the message preview will resolve with live data so you can proof all your templates before going Active.

Step 3: Update Salesforce Flows for Automated Enrollment

If you use Salesforce Flows to automatically apply cadences to records based on conditions, you'll need to update those flows to reference a Cadence Library instead of individual folder combinations.

  • Open the new Cadence Library Flow in Flow Builder. [need to grab official name]

  • Locate the step where a Cadence Library values is assigned.

  • Select a single Cadence Library reference to be added to records, and set the conditions of when the flow should run.

  • Save and activate the updated Flow.

  • Once you have activated the new Flow, immediately go de-activate the old Cadence flow.

Step 4: Manage and Maintain Libraries Over Time

  • Clone a library — Use the Clone button on any library to duplicate it, including all steps. The clone defaults to Draft status so you can modify it safely before publishing. The name will append "- Clone" automatically.

  • Edit a template — Select any step in the timeline and click Edit in the preview panel. Note that changes to a template affect every library that uses it — a warning will appear before you save.

  • Remove a template from a library — Click Remove in the preview panel. This removes the step from the library only; it does not delete the underlying template from your org.

  • Monitor libraries in the list view — The Cadence Library list view shows SMS, Email, Task, and Direct Mail counts at a glance for every library, along with status. Use the object-type filters to narrow the view by Lead, Contact, Opportunity, and more.

Step 5: Go All-In on Cadence Libraries

When you've migrated your existing folders, built out your new libraries, and updated your Flows, you're ready to fully transition over to the new experience. This final step hides all legacy folder options so your team works exclusively with Cadence Libraries going forward.

  • In the Cadences Setup tab, locate the toggle to complete your migration [toggle name placeholder].

    Click the toggle — a confirmation modal will appear. Review it carefully before confirming.

    Once enabled, the following are permanently hidden from your org's UI:

    • The Migrate Folders to Cadence Library wizard in Cadences Setup

    • The + Add Existing Folder button in the library builder

    • The folder/library toggle in the Create Cadence modal, and the folder options. Only the Cadence Library option will remain

    ⚠️ Things to Keep in Mind — This is a one-way switch via the UI. If you need to revert after enabling, you'll need to submit a Left Main support case for a manual settings change. Make sure your migration is complete and your team is ready before flipping this toggle.
