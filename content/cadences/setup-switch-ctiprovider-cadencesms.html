Set Up or Switch Your CTI Provider for Cadence SMS

Overview

Vonage, DialPad, and CallRail are now available as CTI providers in Left Main, using a new, more secure setup process. Use this guide to set up or switch to one of these providers in Cadence Setup — whether you're a new customer completing implementation or an existing customer switching providers.

Prerequisites

  • System Administrator (or equivalent) Salesforce permissions.

  • Your credentials from your provider's account:

    • Vonage: API Key, API Secret, Application ID, and Default Sending Number.

    • DialPad: API Key and any additional fields specific to DialPad.

    • CallRail: Account Number, Token, and Default Tracking Number.

Steps

  1. Navigate to Cadence App Configuration and open Cadence Setup.

  2. Click Edit.

  3. Scroll to step 2, Configure Outbound SMS Provider, and click Change SMS Provider.

  1. In the SMS Provider field, open the dropdown and select your provider.

  2. Enter the credential fields that appear for your provider:

    • Vonage: API Key, API Secret, Application ID, and Default Sending Number.

    • DialPad: the fields specific to DialPad shown in the form.

    • CallRail: Account Number, Token, and Default Tracking Number.

  3. Click Save and Lock Provider.

If you're switching to Vonage specifically, complete this additional step:

  1. Go to Setup.

  2. In Quick Find, search for Remote Site Settings.

  3. Find Vonage_SMS.

  4. Click Edit.

  5. Select the Active checkbox and confirm it's set to true.

  6. Click Save.

Note: Once you click out of a credential field, the value is hidden and can't be viewed again. If you need to change it later, just re-enter it.

Expected Outcome

Your provider is set as your CTI provider for Cadences, and outbound SMS sends from the number you configured. We recommend sending a test SMS to a test record to confirm everything is working properly.

Things to Keep in Mind

  • If you're already set up with Vonage, DialPad, or CallRail and aren't switching, you don't need to do anything — your current setup carries over.

  • New customers: the Left Main implementation team will complete this setup with you during implementation.

  • If you want to use a softphone and your provider supports it, that's set up separately from this guide.


Pro Tip 🧠

Have your provider credentials ready from your provider's account before you start, so you're not searching for them mid-setup.
