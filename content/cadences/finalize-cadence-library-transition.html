1. Navigate to the Cadence App Configuration app.

  2. Go to Cadences Setup.

  3. Click 'Edit'.

  4. Review the description to confirm readiness for full transition to the new Cadence experience.

  5. If ready, enable the transition using the toggle.

  6. Click 'Finalize'.

  7. Click 'Save'.

  8. Navigate to the Cadence Library section.

  9. Open a Cadence Library (e.g., Demo Cadence Library).

  10. Verify that the '+ Add Existing Folder' option is no longer available.

  11. Click 'App Launcher' to continue navigating Salesforce.

Key Notes

  • Finalizing the transition permanently removes access to legacy folder methods.

  • After finalization, only Cadence Libraries can be used.

  • Ensure all necessary folders and data have been migrated before completing this step.

  • This action should be coordinated and communicated across teams.
