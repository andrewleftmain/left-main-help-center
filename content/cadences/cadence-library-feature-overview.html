Cadence Libraries

Release Date: April 29, 2026

Overview

Cadence Libraries replace the old folder-based cadence system with a single, unified container that holds all your outreach sequences — SMS, email, tasks, and direct mail — in one coordinated timeline. Instead of selecting up to four separate folders every time you create a cadence on a record, you now pick one library and every step across every channel is automatically applied.

The old system gave you no visibility into what a folder actually contained, let alone how multiple folders worked together. Cadence Libraries solve that by letting admins build, preview, and publish complete outreach sequences before they're ever applied to a record.

Who is this for?

  • Admins who build and manage outreach sequences for their team

  • End users who apply Cadences to leads, contacts, opportunities, transactions, and interested buyers

When should they use it? Cadence Libraries are the new default experience for creating and managing cadences. New cadences should be built in libraries. Existing folder-based cadences continue to work, and teams can migrate on their own timeline.

Key Capabilities

  • Single-library selection — Apply one Cadence Library to a record instead of choosing up to four separate folders. All SMS, email, task, and direct mail steps are added automatically.

  • Timeline view — See every step of your outreach sequence in chronological order, with the number of days between touchpoints shown visually. Spot gaps, overlaps, or timing issues.

  • Template preview with real data — Select any record from your org to resolve merge fields in the preview, so you can proof messages with actual names, addresses, and data.

  • Draft / Active status — Libraries stay in Draft until you're ready. Only Active libraries appear in the cadence picker on records, preventing incomplete sequences from being accidentally applied.

  • Build from scratch or reuse existing templates — Create and add new templates directly in the library builder, or pull in templates that already exist in your org. Filter by type and object to find compatible sequences quickly.

  • Clone any library — Duplicate an entire library — all steps included — to create variations or test versions without starting over.

  • Bulk Cadences — Apply a Cadence Library to multiple records at once from a list view.

  • Gradual migration from folders — Import sequences from existing folders into a new library using the migration wizard in Cadences Setup, or pull folders in incrementally using the "+ Add Existing Folder" button in the builder. The old system and new system coexist during transition. Once the transition is complete, a toggle in Cadence Setup migrates your system fully to Cadence Libraries

  • Cadence timeline on records — Once a library is applied to a record, a timeline component shows the full sequence with real-time status indicators: completed (green), failed (red), or pending.

When to Use It

  • Starting a new outreach strategy — Build it as a Cadence Library from the start so it's organized, preview-able, and ready to reuse across any record of that type.

  • Replacing a messy folder setup — If your team has been managing four separate folders per cadence and struggling to keep them in sync, migrate them into a single library for a cleaner, more maintainable experience.

  • Auditing or QA-ing an existing cadence — Use the timeline view and merge field preview to verify message content, timing, and sequence order before a campaign goes live.

  • Creating variations of an existing cadence — Clone a library and adjust timing or messaging without disrupting the original.

  • Applying the same sequence to multiple records at once — Use bulk enrollment from a Lead or Opportunity list view.

  • Automate Cadences with Flows — Use Salesforce Flows to automatically apply a Cadence Library to a record when conditions are met. If you're already using Flows to assign folder-based cadences, you can update them to reference a single Cadence Library instead.
