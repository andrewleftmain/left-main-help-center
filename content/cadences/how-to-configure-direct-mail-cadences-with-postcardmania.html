Steps

Assign Permission Sets

Before users can access Direct Mail functionality, they must be assigned the appropriate permission set group based on their role. There are two roles to consider:

  • Direct Mail Administrators — Users who will configure the Direct Mail setup, including PostcardMania connectivity, address field mappings, and cadence creation. This is typically a small group of admins.

  • Direct Mail Users — Users who will apply Direct Mail Cadences to leads, contacts, and opportunities but do not need access to configuration settings.

Permission Set Groups

Assign one of the following permission set groups to each user based on their role:

Role

Permission Set Group

Direct Mail Administrator

Left Main Direct Mail Admin Permission Set Group

Direct Mail User

Left Main Direct Mail User Permission Set Group

How to Assign a Permission Set Group

  1. In Salesforce, go to Setup

  2. Search for Permission Set Groups

  3. Select the appropriate group based on the user's role (see table above)

  4. Click Manage Assignments

  5. Click Add Assignment

  6. Select the users to assign and click Assign

Repeat this process for each permission set group as needed.

Note: If your org restricts assignment of the Left Main User permission set, see the bottom of this guide for an alternative configuration path.

Note: Users who do not have one of these permission set groups assigned will not be able to access or use Direct Mail functionality.

Access the Direct Mail Configuration Settings

  1. From the app launcher, search for and open the Cadence App Configuration app.

  2. Navigate to the Cadences Setup tab.

  3. At the top of the Setup page, check the checkbox for Direct Mail to enable the feature

  4. Next, scroll to the bottom of the page to locate the Configure Direct Mail section.

There are three actions to complete in this section:

1. Manage Your Direct Mail Account

  1. Click Manage Direct Mail Account.

  2. You will be directed to PostcardMania.

  3. If you have not yet created or configured your PostcardMania account, complete that setup here before proceeding.

2. Configure Default Recipient Address Settings

  1. Click Default Recipient Address Settings.

  2. In the modal that opens, configure the field mappings by selecting which Salesforce fields from your org should be used to populate the direct mail recipient address. These fields will appear in the address block on the physical mail piece.

  3. Use each picklist to assign the appropriate field for each address component.

  4. When you are satisfied with your mappings, click Save.

3. Prepare Records for Direct Mail

Before direct mail can be sent, Left Main must copy your address and name fields into special mailing fields based on your recipient address settings from the previous step. This is a one-time step — after it is completed, your records will stay up to date automatically.

  1. Click Update Records.

  2. In the Prepare Records for Direct Mail modal, click the button to run the update for each record type:

    • Prepare All Leads

    • Prepare All Opportunities

    • Prepare All Contacts

  3. This will update all existing records in your org.

    • Note: You may rerun any of these if errors occur.

  4. When the update is complete, you will receive a confirmation email.

  5. If any errors occur, you will receive an error report. Make the necessary corrections and retry.

Optional: Alternative Permission Configuration (Without Left Main User)

Both permission set groups above include the Left Main User permission set. If your org restricts assignment of Left Main User, you can manually assign the following individual permission sets to each user instead of using the permission set group.

Alternative for Direct Mail Users:

  • Left Main Cadences Permission Set

  • Left Main Direct Mail Core User Permission Set

  • Left Main Direct Mail Mapping Access

  • PostcardMania User

  • Left Main Direct Mail Extension User Permission Set

Alternative for Direct Mail Administrators:

  • Left Main Cadences Permission Set

  • Left Main Direct Mail Core User Permission Set

  • Left Main Direct Mail Mapping Access

  • PostcardMania Admin

  • PostcardMania Manager

  • PostcardMania User

  • Left Main Direct Mail Extension User Permission Set

  • Left Main Direct Mail Core Administrator Permission Set

These must be assigned individually — there is no permission set group for this configuration. Each permission set will need to be assigned to the user following the same steps outlined above.

If you need help determining the right setup for your org, please reach out to our support team.
