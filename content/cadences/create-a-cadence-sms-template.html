How-To-Use Guide

Create a New SMS Follow Up Sequence

  1. Navigate to the SMS Template Follow Up Sequences tab.

  2. Click New.

  3. Complete the four sections in the New SMS Template modal:

    1. Template Details

      1. Enter a Template Name.

      2. Select the Object this template will be used for.

      3. Choose an existing Folder, or click + Create New to add a new folder.

        1. Selecting Create New opens a new tab in Setup where you can create the folder.

        2. Once saved, close the tab and return to the SMS Template modal.

    2. Message Content

      1. Enter the SMS message text.

      2. Use the Merge Field Picker to search for and insert merge fields.

        1. Place your cursor where you want the merge field to appear, then select the field to insert it.

    3. Schedule Message

      1. Choose when the SMS should be sent once the Cadence step is applied:

        1. Immediately – Sends as soon as the step is applied.

        2. After X Minutes / Hours / Days – Sends after a specified delay.

        3. On a Specific Day of the Week – Sends at a set time on a selected weekday and can repeat for multiple weeks.

        4. On a Specific Date – Sends on an exact date and time.

    4. Message Preview

      1. Search for and select a record to preview the message.

        1. Note: The options listed will be the most recent 100 records created of that record type

      2. Review the rendered message and character count.

  4. Click Save.

  5. You’ll be taken to the SMS Follow Up Sequence record, where you can continue testing previews with other records.

  6. Click the SMS Template Follow Up Sequences tab to return to the full template list.

Edit an Existing SMS Follow Up Sequence

  1. Navigate to the SMS Template Follow Up Sequences tab.

  2. Select a template from the list view.

  3. Click Edit.

  4. Make your updates.

  5. Click Save.

  6. You’ll return to the template record, where you can continue previewing with different records.

  7. Click the SMS Template Follow Up Sequences tab to return to the list view.
