Bulk Add or Remove Cadences

  1. Navigate to the Left Main home page.

  2. Go to a list view where you can select multiple records.

  3. Select the desired records.

  4. Click the action dropdown menu.

  5. Click 'Bulk Add Cadence'.

  6. If needed, check the checkbox next to any record you want to remove from the selection.

  7. Click 'Remove from List' to exclude that record.

  8. Click 'Remove' to confirm removal.

  9. During the migration phase, choose between the Legacy Folder method or the Cadence Library method using the toggle.

  10. Click 'Select a Cadence Library'.

  11. Choose the desired Cadence Library.

  12. Confirm and apply the cadence to the selected records.

Key Notes

  • You can add cadences to multiple records at once using list views.

  • Records can be removed from the selection before applying the cadence.

  • Both legacy and Cadence Library methods are available during migration.

  • After migration, only Cadence Libraries will be used.
