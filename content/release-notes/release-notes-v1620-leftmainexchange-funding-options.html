Release Notes v1.620: Left Main Exchange Funding Options

Release Date: August 31, 2026

New: Funding Options, Right Inside Left Main REI

Overview

Funding Options makes it easier to move from deal to funding without leaving your Left Main REI workflow.

From a Transaction, you can now review available financing options, understand how each option works, and take the next step with a lender using information already available in your CRM.

The first release includes integrations with QuickDraw Funding and Renovo Financial.

What Changed

Access Funding Options from a Transaction

The new Funding Options experience is available directly from the Transaction page in Left Main REI.

From Funding Options, you can:

  • Review available funding providers.

  • Learn what each financing option is designed for.

  • Send relevant deal information directly from the Transaction.

  • Take the next step with a lender without re-entering information already stored in Left Main REI.

QuickDraw Funding

QuickDraw provides very short-term transactional funding for double-close transactions.

QuickDraw may be a fit when you need capital to complete the A→B purchase before the B→C sale to your end buyer closes.

From the QuickDraw option in Left Main REI, you can:

  • Review the status and available capacity of your firm's shared credit line.

  • Review QuickDraw transactional funding terms.

  • Request funding for the Transaction you're currently working on.

  • Prefill the request using information already stored on the deal.

  • Track the status of your funding request from the Transaction.

Renovo Financial

Renovo provides fix & flip and DSCR rental financing through a specialist-guided process.

From the Renovo option in Left Main REI, you can:

  • Review the types of financing Renovo offers.

  • Review how the Renovo funding process works.

  • Introduce your current deal to Renovo.

  • Send relevant property, deal, and contact information from the Transaction.

After an introduction is submitted, a Renovo lending specialist will reach out within one business day to discuss the deal and potential financing options. There is no commitment or fee to start the process.

Getting Started

The first time you use Funding Options, complete the one-time activation process:

  1. Open Funding Options from your Left Main REI workflow.

  2. Enter your email address.

  3. Check your email for a six-digit verification code.

  4. Enter the verification code in Left Main REI.

  5. After verification, your available QuickDraw and Renovo funding options will appear in the Funding Options section.

You only need to complete this activation once.

Who Is Affected

Funding Options is available from the Transaction page.

If your organization uses the standard Transaction page provided with Left Main REI, the new Funding Options component will appear automatically.

If your organization uses a customized Transaction page, a Salesforce administrator may need to add the Funding Options component before users can access it.

Admin Action Required for Custom Transaction Pages

No configuration is required for organizations using the standard Left Main REI Transaction page.

If your organization has customized its Transaction page, your Salesforce administrator will need to add the Funding Options component to the applicable Transaction Lightning Record Page.

Once the component is available, users can complete the one-time activation process and begin reviewing funding options from their Transactions.

Which Funding Option Should I Use?

Need very short-term funding for a double close?
Start with QuickDraw Funding.

Need fix & flip or DSCR rental financing?
Start with Renovo Financial.

Funding Options keeps the financing process closer to the deal you're already managing, reducing duplicate data entry and the need to move between systems.
