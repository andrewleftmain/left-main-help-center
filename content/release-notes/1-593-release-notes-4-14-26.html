Release Date: 4/14/2026

Summary

This release addresses issues introduced in the 1.587 release related to new permission settings for direct mail enhancements.

New Features

New Direct Mail Mapping Permission Set

A new permission set, Left Main Direct Mail Mapping Access, has been created to grant the specific object and field-level access required for Direct Mail mapping functionality. Initially, this access was bundled into the Left Main User permission set, which caused issues for users who need Direct Mail access without the full Left Main User assignment. Administrators can now assign this permission set independently to support flexible, customer-specific permissions.

Bug Fixes

Direct Mail Error Fix

Resolved an issue where certain users could encounter errors when saving or updating Leads, Opportunities, or Accounts due to missing Direct Mail permissions. Users will now be able to save and update records successfully even if Direct Mail access has not been configured for them.
