What’s New in v1.541?

Estimated Market Data Points Now Displayed

The Property Sales AI Admin Panel now displays the number of Market Data Points in your org. Market Data Points refers to the total number of Lead and Opportunity records in your org. This total changes as you make record type, lead status and opportunity stage selections within the Property Sales AI Admin Panel prior to activation. The final total reflects the number of Lead and Opportunity records actively scanned for address matches, improving visibility into usage-based pricing and data footprint. Upon activation, this number is expected to fluctuate after each weekly address matching run.

New “Property Sale Duration” Field

A new field, Property Sale Duration, has been added to the Subscription page layout. Use this field to set the number of days used to determine whether multiple Property Sales records should be treated as duplicates.

This field helps you manage data hygiene by accounting for variations in local recording timelines. If two property sales share the same LFID (unique identifier) and occur within the number of days specified here, they’ll be considered duplicates. If outside of the date range specified here, they’ll be treated as uniquely separate transactions. Different values may be used per county.

We recommend entering a value between 7 and 20 days to reduce false duplicates while preserving legitimate sales activity.

Bug Fixes in v1.541 🐞

Duplicate Property Sales Fix

We resolved an issue where minor fluctuations in recording dates caused multiple entries of the same Property Sale. This fix improves the accuracy of Market Insights reports and prevents record clutter.
