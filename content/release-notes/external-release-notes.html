Cadence Template Refresh

We’ve refreshed how SMS and Email templates work in Cadences to make creating, editing, and scheduling messages faster, easier, and more powerful. These updates streamline the experience across SMS and Email while unlocking more flexible design and personalization options.

Unified SMS & Email Template Creation

Creating and editing SMS and Email templates now follows a consistent workflow. This makes it easier to build, preview, and manage templates without jumping between multiple screens.

  • SMS Templates now include all inputs on one screen, with the ability to preview messages using a selected record before saving.

  • Email Templates are now powered by Salesforce Lightning Templates, allowing for more visually appealing and modern email designs.

    • Note: Existing classic templates can still be used, but all new templates are created using Lightning going forward.

    • Required Step: To enable users to create new Lightning email templates, admins must perform a one-time post-install configuration. Reference the How To Use documentation here or this link for step-by-step instructions.

  • Check out the How-to-Use Documentation for more details:

    • Create a Cadence SMS Template

    • Create a Cadence Email Template

Flexible Email Design Options

When creating a new Email template, users can choose between two creation experiences based on their needs:

  • Basic Editor – A simple, text-only editor with merge field support.

  • Salesforce Email Builder – A drag-and-drop builder with layout blocks and components, plus full merge field support for dynamic content.

Improved Scheduling Options

Scheduling Cadence messages is now more flexible than ever, with four clear options for when messages are sent:

  • Immediately – Sends the message as soon as it’s applied to a record.

  • After X Minutes, Hours, or Days – Sends after a defined delay.

  • On a Specific Day of the Week – Sends at a set time on a chosen weekday, recurring for a specified number of weeks.

  • On a Specific Date – Sends on an exact date and time.

Enhanced Merge Field Picker

The Merge Field Picker has been upgraded to make personalization easier and faster:

  • Added support for select User and Organization fields.

  • Interested Buyer merge fields now support both Contact and Transaction data.

  • Fields are organized by object and alphabetized for easier browsing.

  • A new search option lets you quickly find the field you need.

  • Merge fields can now be used in Email Subject Lines, not just the body.

Faster Folder Setup

Creating new template folders is now simpler, with a direct button that takes users to the correct Setup screen—no more manual navigation required.
