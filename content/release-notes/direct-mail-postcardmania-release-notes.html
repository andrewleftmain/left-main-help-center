Release Date: April 29, 2026

Summary

This release introduces Direct Mail Cadences — a major new channel for Left Main's Cadences. Users can now automate the delivery of physical mail pieces to Leads, Contacts, and Opportunities, completing a true multi-channel outreach strategy alongside existing SMS and Email Cadences. All mail templates are created through our new partner platform, PostcardMania.

Removed Components

Buttons

  • Create Direct Mail Cadences removed from Lead, Opportunity, Contact

  • Direct Mail button removed from Campaign

Page Layout Components (Lead, Opportunity, Contact, Campaign)

The following Direct Mail components have been removed where present:

  • Direct Mail Address sections

  • Direct Mail Orders related lists

  • Direct Mail Sent Status

  • Cadence Direct Mail, Direct Mail Orders, and Direct Mail Sent Status related list quick links

  • Any additional Direct Mail-related sections, buttons, or components

Automation

  • All Direct Mail scheduled jobs deleted

  • All Direct Mail-related flows deactivated

Apps, Permissions, and Settings

  • Direct Mail App removed

  • Direct One permission set removed

  • Remote Site Settings deactivated:

    • Directmail

    • Directmailleftmain

    • Directone1

New / Updated Components

Application

  • PostcardMania App installed in Salesforce

Buttons

  • Send Direct Mail added to:

    • Lead

    • Opportunity

    • Contact

    • Campaign

  • Create Cadence now includes Direct Mail (separate Direct Mail cadence button removed)

Related Lists

  • Related Orders added to:

    • Lead

    • Opportunity

    • Contact

Permission Sets

  • Left Main Direct Mail Admin Permission Set Group (Admins)

  • Left Main Direct Mail User Permission Set Group (Standard Users)

Setup Changes

  • New Configure Direct Mail section added in Cadences Setup

  • Connected App settings updated for PostcardMania

Functional Changes

  • Direct Mail now powered by PostcardMania (Salesforce app)

  • Templates are created and managed within the PostcardMania app

  • Billing model updated from credit-based → PostcardMania budget-based system

User Impact

  • Legacy Direct Mail UI and functionality removed

  • Direct Mail is now accessed via:

    • PostcardMania App

    • Send Direct Mail button

    • Standard Cadence creation flow

  • Existing Cadences and templates may require updates

Action Required

  • Assign new Direct Mail permission set groups

  • Train users on PostcardMania and updated workflow

  • Review page layouts if customizations exist

  • Validate Connected App access
