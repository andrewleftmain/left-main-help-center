Release Date: April 29, 2026

Summary

Cadence Libraries give your team complete visibility into what a cadence does before applying it. Instead of piecing together four separate folders and hoping they work, you now build one unified library and see your entire outreach sequence laid out day by day.

New Features

  • Cadence Libraries ✅ — A single container that holds all your outreach sequences — SMS, email, tasks, and direct mail — for a specific record type. Each library has a name, description, and status (Draft or Active) so users always know what they’re selecting before they apply it.

    • Draft status prevents incomplete Cadences from being accidentally applied

    • Clone any library to create variations without starting from scratch

    • Works with Leads, Contacts, Opportunities, Transactions, and Interested Buyers

  • Cadence Timeline View ✅ — See every step of your cadence in chronological order. On the Cadence Library , users see the full day-by-day sequence with previews across all channels so admins can spot gaps, overlaps, or timing issues at a glance. On record pages, users will see the full sequence over time with status indicators.

    • Day-by-day view of all SMS, email, task, and direct mail steps

    • Days between touchpoints shown in green

    • Click any step to preview the full message content with real merge field data

  • Migration Tools ✅ — Existing folder-based cadences are preserved. You can migrate on your own timeline using the migration wizard in Cadences Setup, or by pulling folders into a library one at a time using the “+ Add Existing Folder” button in the builder.

Enhancements

  • Bulk Cadences are now supported for Direct Mail.

Known Issues

  • This release includes updates to packaged Left Main permission sets. Customers with cloned or custom permission sets may encounter an error when creating cadences in Library mode. Visit the Getting Started Guide for more details.

  • A flow “Lead Created - Library Cadence” was previously activated in error. This release has resolved the issue. No customer action required.

Deprecations

The four-folder selection UI in the Create Cadence modal will be deprecated in favor of Cadence Libraries. It remains accessible via the Library/Folder toggle during migration. Once migration is complete, the admin will toggle off the old version of the Create Cadence modal leaving just Cadence Libraries.

Things to Keep in Mind

Old folder-based cadences continue to work on existing records. Nothing is disrupted when you activate Cadence Libraries.

Completing migration (hiding the legacy folder UI) is a one-way switch via the UI. Reverting requires a Left Main support case.

The migration completion toggle includes a prominent warning before activating.


Pro Tip 🧠

In the Cadence Library builder, use the Preview Record field to select a real record from your org. All merge fields in the message preview will resolve with live data so you can proof your templates before going Active.
