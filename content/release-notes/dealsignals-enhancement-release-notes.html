Release Notes v1.598

Release Date: May 6, 2026

Summary

This release includes improvements to DealSignals eviction record processing, enhancing how property ownership and associated parties are represented in your CRM.

Previously, eviction records could result in prospects being created from defendants/tenants, making it difficult to consistently target property owners. With this update, prospect records now accurately represent the property owner, while defendants/tenants are captured as related contacts—resulting in improved data accuracy, clearer relationships, and better targeting.

New Features

  • Updated DealSignals eviction processing to distinguish between property owners and defendants/tenants

  • Automatic creation of related contacts for defendants/tenants linked to eviction records

Enhancements

  • Prospect records generated from DealSignals eviction data now represent the property owner by default

  • Defendants/tenants are stored as related contacts, improving visibility into all parties tied to a property

  • Improved logic for handling owner names provided as a single full name

  • When no first/last name breakdown is available, records are automatically classified as organizations for better data consistency

Known Issues

  • Owner records created from single-name inputs may occasionally require manual review if incorrectly classified as an organization

Notes and Resources

  • Contact Support: support@leftmainrei.com

  • Documentation: https://docs.leftmainrei.co/

  • Additional Notes:

    • These updates apply specifically to DealSignals eviction data ingestion and processing

    • Existing records will not be retroactively updated unless reprocessed

    • Users should review automations, list views, or reporting that previously relied on defendant-based prospect creation

Special Callouts to Use

Things to Keep in Mind

  • Prospect records will now prioritize property owners instead of tenants/defendants

  • Defendants/tenants will no longer be created as primary prospects

  • Related Contacts should be used to track non-owner individuals tied to a property

  • Reporting and outreach strategies may need slight adjustments if previously based on tenant data

Pro Tip 🧠

When working DealSignals eviction records, focus your outreach on the prospect (property owner) and use Related Contacts to reference tenants/defendants—this keeps your pipeline clean and ensures you're targeting the true decision-maker.
