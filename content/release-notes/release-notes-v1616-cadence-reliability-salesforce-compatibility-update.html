Release Notes v1.616: Cadence Reliability and Salesforce Compatibility Updates

Release Date: August 13, 2026

Summary

This release includes reliability and compatibility fixes across Left Main. We've improved Stop Cadence processing in automated scenarios and updated affected buttons to remain compatible with Salesforce's Lightning Web Security requirements.

No customer action is required for the changes in this release.

Bug Fixes

Stop Cadence Reliability

Fixed: Stop Cadence actions failing in certain automated scenarios

Resolved an issue where Stop Cadence could fail to run when triggered from an automation that was already processing work in the background. In certain scenarios, Salesforce processing limits were reached before the cancellation completed.

We have updated how Stop Cadence handles these scenarios so cancellation requests complete reliably, even when other automations are running at the same time.

Pending SMS, email, direct mail, and task steps are cancelled as expected when a cadence is stopped.

Button Compatibility with Salesforce Lightning Web Security

Fixed: Certain buttons not responding after a Salesforce security update

A Salesforce Lightning Web Security update changed how links are allowed to open, causing certain Left Main buttons to stop responding when clicked.

We have updated the affected buttons to work correctly with Salesforce's security requirements. This includes buttons that open a builder or template in a new tab, such as Create New and Edit Template on Email Follow Up Sequence records.

The fix has been applied across the affected areas of Left Main. There is no change to the expected user experience. The buttons will simply respond as expected.
