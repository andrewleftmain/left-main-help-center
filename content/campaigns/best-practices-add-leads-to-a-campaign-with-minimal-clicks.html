1. Use List Views for Segmentation

  • Create a custom List View with filters for your target segment (e.g., “Lead Source = Google Ads” or “City = Charlotte”).

  • Include key columns like “Campaign” to check if leads are already part of a Campaign.

2. Add Leads via Mass Actions

  • Select all leads in the List View.

  • Click the “Add to Campaign” button (if enabled).

  • Choose the target Campaign and update Member Status in bulk.

3. Use Salesforce Reports for Advanced Segments

  • Create a report (e.g., “Leads with Campaign History”) to refine your audience.

  • From the report view, select leads and add them to a Campaign.

4. Automate with Flows for Recurring Segments

  • Set up a scheduled Flow to automatically add leads meeting certain criteria to a Campaign (e.g., new leads created in the past week).
