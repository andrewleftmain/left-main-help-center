How to Check Your Left Main Package Version

You may need to verify your Left Main package version when:

  • Reviewing release notes

  • Confirming whether a recent update has been installed

  • Troubleshooting an issue with the Left Main Support team

Follow these steps to check which version of Left Main is installed in your Salesforce org:

  1. Navigate to Setup in Salesforce.

  2. In the Quick Find search box, search for Installed Packages.

  3. Select Installed Packages.

  4. Locate Left Main in the package list.

  5. Review the Version Number column.

Example:

Left Main → v1.606

Comparing Your Version to Release Notes

The version listed in Installed Packages should match the version referenced in the latest Left Main release notes.

If your version is lower than the version listed in the release notes, your organization may still be in the rollout process.

Need Help?

If you have questions about your package version or believe an update is missing, please contact the Left Main Support team at support@leftmainrei.com.
