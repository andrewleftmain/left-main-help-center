Project Management App: Installation and Post-Installation Configuration

Overview

Use this guide to install and configure the Left Main Project Management App in a customer's Salesforce org.

This article covers:

  • Installing the managed package

  • Importing Labor Item Templates

  • Importing Project Templates

  • Updating and importing Milestones

  • Configuring Transaction actions

Before You Begin

Before starting, ensure you have:

  • System Administrator access to the customer's Salesforce org.

Download Required Files

Before beginning the installation, download the following CSV templates from the Attachments section of this article:

  • Project Management Labor Item Templates.csv

  • Project Management Project Templates.csv

  • Project Management Milestones.csv

You'll use these files throughout the setup process. The Milestones.csv template will be updated later in this guide before it is imported.

Step 1 – Import Labor Item Templates

Navigate to Project Management from the App Launcher.

Open the Labor Item Templates tab and click Import.

Upload the Labor Item Templates.csv file using the Data Import Wizard.

Select LABOR ITEM TEMPLATES, ADD NEW RECORDS, CSV, CHOOSE FILE and upload the completed LABOR ITEM TEMPLATES .csv file

Step 2 – Import Project Templates

Open the Project Templates tab and click Import.

Select PROJECT TEMPLATES, ADD NEW RECORDS, CSV, CHOOSE FILE and upload the completed PROJECT TEMPLATES .csv file

Mapping

Do not map:

  • Record Type

  • Record Owner

Map:

  • Template

Click Next, then Start Import.

Step 3 – Update the New Build Record Type

After importing, both project templates will have the same Record Type.

Select the New Build Template.

Click ▼ > Change Record Type.

Change the Record Type to:

New Build

Save the record.

Step 4 – Update the Milestones CSV

Before importing milestones, the Project IDs must be updated.

Important: Column H is unique to every customer. The last four rows in column B are in reference to the Renovation template. The rest of the rows are for the New Build template.

New Build

Open the New Build Template project.

Select and copy the Project ID from the browser URL.

Paste the Project ID into Row 2, Column H of the Milestones spreadsheet.

Click the bottom right corner of the Row 2, Column H cell and drag down to Row 29.

Renovation

Open the Renovation Template project.

Copy its Project ID.

Paste it into Row 30, Column H.

Drag the value down through Row 33.

Save the spreadsheet as a CSV before importing.

Step 5 – Import Milestones

Navigate to:

Setup → Data Import Wizard

Select Custom Objects.

Scroll down and select Milestones.

Select Add New Records. Then select CSV.

Import the updated Milestones CSV. Then click Next.

Map these fields

CSV Field

Salesforce Field

Expected Days Required

Expected Days Required

Kickoff Date

Kickoff Date

Is Completed

Is Completed

Project

Project

Click Next, then Start Import.

After the import finishes, open each Project Template and verify the Milestones related list contains records.

Step 6 – Create Transaction Actions

Navigate to:

Setup → Object Manager → Transaction

Select:

Buttons, Links, and Actions

Create the following buttons:

  • New Build Project

  • Renovation Project

Use Create a Record as the Action Type.

Step 7 – Add Buttons to the Transactions Page Layout

Open the Transaction Page Layout.

Under Salesforce Mobile and Lightning Experience Actions, add:

  • New Build Project

  • Renovation Project

Save the layout.

Verification

Open any Transaction record.

You should now see:

  • New Build Project

  • Renovation Project

Clicking either button should create the appropriate Project record.

Installation Complete

The Project Management App has now been installed and configured for the customer's Salesforce org.

Verify the following before closing the implementation:

  • ✅ Labor Item Templates imported successfully.

  • ✅ Project Templates imported successfully.

  • ✅ Milestones imported and associated with both Project Templates.

  • ✅ Transaction actions have been added to the page layout.

  • ✅ The New Build Project and Renovation Project buttons are visible and functioning as expected.

The Project Management App is now ready for use.
