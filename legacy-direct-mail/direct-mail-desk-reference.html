Discover Left Main’s Direct Mail App

Direct mail has long been recognized as a highly effective marketing channel for real estate investors. It allows for a more tangible connection with potential leads, cutting through the noise of digital marketing and presenting an opportunity to make a lasting impression. However, traditional direct mail campaigns can be time-consuming and inefficient, making it challenging for investors to execute targeted strategies at scale.

Left Main REI’s Direct Mail App changes the game by streamlining the direct mail process and empowering investors to run highly targeted campaigns with ease, all from within the platform they already rely on!

What You Need to Know

Cost Per Piece

1 credit = $1

Postage

Mailer postage is a physical, first class stamp.

Timeline

  • PDF proofs arrive in user's inbox within approximately one minute after selecting the Generate Preview button

  • Order cancellation deadline: 12am EST on day of approved order

  • Orders processed: approximately 4am EST the day after order is approved

Return Mailing Address and Contact Info

The return mailing address is the address entered in the Company Setup tab. The company contact info on the mailer will be the contact info in the Company Setup tab by default. Custom contact info can be applied if sending Direct Mail via the Campaign object.

Recipient Address Fields

Three sets of address fields are relevant to Direct Mail:

  • Address (required)

  • Customer Street, Customer City, Customer State Customer Zip (optional and only used if the contact’s mailing address differs from the target investment property)

  • Property Street, Property City, Property State, Property Zip (required)

Considerations

Direct Mail Cadence Orders Trump Regular Direct Mail Orders

When adding a lead to a direct mail cadence, logic does not respect the 30-day rule of restricting the first "now" mail piece order when there was a regular direct mail order created in the last 30 days.

When creating a regular direct mail order, logic does respect a cadence order having been placed in the last 30 days and stops the new regular order.

This functionality allows for users to create direct mail sequences that mail out more frequently then every 30 days if they choose.

Cancelling Orders

If you decide to cancel after approving an order, you have up until 12am EST to do so. If order is rejected, a note will show up on Direct Mail Order submission page. By about 4am, you should have a response confirming an order has been processed. Orders drop next day unless an order is submitted on a Saturday, in which case it drops on Monday.
