Transaction Expense Loan Payoff PDF Permission Requirements

Transaction Expense Loan Payoff PDF Permission Requirements

Applies to: Left Main Release v1.615

Overview

As part of an upcoming security enhancement, Left Main is updating the Transaction Expense Loan Payoff PDF Generation feature to comply with Salesforce security best practices.

When users generate a Loan Payoff PDF from a Transaction Expense record with the Record Type = Lender, Left Main will now enforce Salesforce object and field-level security (FLS) before generating the document.

Previously, the PDF generation process did not validate whether the logged-in user had permission to view all fields included in the PDF. As a result, users could generate documents containing sensitive information even if their Profile or Permission Sets did not grant access to those fields.

Beginning with this release, users must have the required object and field permissions or the PDF generation will fail with an error.

What Changed?

The Loan Payoff PDF generator now validates that the logged-in user has:

  • Read access to the required Salesforce objects

  • Read access to all fields used to populate the PDF

If any required permission is missing, the PDF will not be generated.

What Happens if Permissions Are Missing?

If the logged-in user does not have access to any required object or field listed above, Left Main will prevent the Loan Payoff PDF from being generated and an error will be displayed.

This behavior is expected and is designed to protect sensitive financial information from being exposed to unauthorized users.

Resolution Options

Customers have two options for granting the required access.

Option 1: Update Profile Permissions

Grant Read access to the required objects and fields on the Salesforce Profiles of users who need to generate Loan Payoff PDFs.

This option is appropriate if all users with the same Profile require access.

Option 2: Create a Permission Set (Recommended)

Create a custom Permission Set (for example):

Left Main Transaction Expense Payoff Generation

Grant Read access to:

  • Required objects

  • Required fields listed above

Assign the Permission Set only to users who need to generate Loan Payoff PDFs.

This approach follows Salesforce best practices by limiting access to sensitive financial information.

Customer Impact

This feature has historically seen limited usage among Left Main customers. As a result, only organizations actively using the Loan Payoff PDF Generation feature are expected to be impacted.

Customers upgrading to this release should verify that users responsible for generating payoff documents have the required object and field permissions before using the feature.

Frequently Asked Questions

Why is this change being made?

The enhancement aligns the Loan Payoff PDF generation process with Salesforce security best practices by enforcing object and field-level security (FLS).

Will existing users be affected?

Only if they generate Loan Payoff PDFs and do not already have the required object and field permissions.

Is this a bug fix?

Yes. The previous implementation allowed users to generate PDFs containing sensitive information even when they did not have permission to view the underlying fields. This release corrects that behavior by enforcing Salesforce security during PDF generation.

Notes

  • This is a security enhancement, not a functional change to the Loan Payoff PDF itself.

  • Consider including this item in the release notes under Breaking Changes or Security Enhancements, as customers with custom security models may encounter permission errors after upgrading.

  • Recommend the Permission Set approach over modifying Profiles to follow Salesforce security best practices.
